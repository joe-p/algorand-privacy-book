# Stealth Addresses

## TL;DR

- Stealth addresses enable anonymous transactions between two or more parties **without sharing any private information**
  - Unlike an HD xPub, one can share their stealth address with two or more people without each person being able to link the transactions from the other people
- Stealth address have two key pairs
  - Spend keypair: The key pair used to spend funds
  - View keypair: The key pair used to view transactions sent to the stealth address
- Stealth addresses require a discovery process that must scan the full blockchain to discover transactions
