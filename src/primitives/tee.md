# Trusted Execution Environments

## TL;DR

- TEEs allow for verifiable compute
- Today the most common form of TEEs is hardware-isolated VMs
  - Allows an entire kernel, OS, and docker compose stack to be verifiable
- TEEs are NOT trust-less
  - Requires trust in the hardware
    - TEE security models explicitly exclude physical access to hardware
  - Requires trust in Intel or AMD
    - TEE integrity verification is dependent on a centralized attestation process from the hardware vendor
